## 📈 How to Get Listed

To be added to this list:

1. **Make a contribution** - Bug fix, feature, documentation, or testing
2. **Submit a PR** - Include your contribution
3. **Get approved** - Maintainer review and merge
4. **We'll add you** - Automatically added upon first PR merge

---

## 🤝 Levels of Contribution

### Tier 1: Bug Reports & Issues
- Found and reported a bug
- Minimum effort: Clear issue description

### Tier 2: Documentation
- Improved README, guides, or comments
- Added examples or tutorials
- Fixed typos or clarified wording

### Tier 3: Small Features
- Added a new benchmark scene
- Improved UI/UX
- Enhanced documentation
- Performance tweaks

### Tier 4: Major Features
- Implemented WebGPU support
- Added major benchmark category
- Significant performance optimization
- Created new testing framework
